# Timber Joints CRM 365

Mobile-first CRM for Timber Joints, a custom sofa and seating business in Bengaluru, India.

## Initial scope
- Customer enquiries and contact details
- Sofa quotations and order records
- Production stages: Enquiry, Confirmed, Frame, Foam, Stitching, Upholstery, Ready for delivery, Delivered
- Advance and balance payment tracking
- Order search, dashboard summaries and CSV export

## Prototype status
The first UI is a browser-only prototype. It stores data in the current browser's local storage. It is not yet a shared production CRM. Before real business use, add secure authentication, a shared database, access controls and backups.

Currency: INR (₹).
